Graph Stream Program

Resource-constrained approximate learning for dynamic graph streams.

This agenda develops principled algorithms for fast-evolving graph streams when memory, computation, and latency are part of the learning problem itself.

Four-Task Agenda

  • Single-pass graph stream processing
  • Approximate graph representations
  • Drift-adaptive learning
  • Robust and interpretable graph AI

Core Methods

  • Adaptive hashing and sketching
  • Compact graph summarisation
  • Approximation-aware learning
  • Efficiency and trust trade-off analysis
