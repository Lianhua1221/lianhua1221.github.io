Flagship Programs

Two interconnected research programs shape my current work.

Program 01

Graph Stream Intelligence

I develop algorithmic foundations for learning from fast-evolving graph streams under strict memory, computation, and latency constraints. This agenda advances a resource-constrained view of graph learning where approximation is not a compromise, but a principled design choice.

  • Single-pass processing of dynamic graph streams
  • Approximate graph representations under bounded memory
  • Drift-adaptive learning under constrained computation
  • Robust and interpretable graph stream learning

Program 02

AI Autism and Neurodevelopmental Screening

I build clinically relevant AI methods for early autism screening by integrating behavioural, neuroimaging, and multimodal signals. The focus is on representation learning that can support earlier, more reliable, and more inclusive screening pathways.

  • Multimodal AI for early autism screening
  • Deep neuroimaging models for autism diagnosis
  • Behavioural and brain-signal integration
  • Trustworthy medical AI for real-world translation

Current Research Agenda

Resource-Constrained Approximate Learning for Dynamic Graph Streams

My current flagship agenda formalises approximate learning for dynamic graph streams under bounded resources. It connects theory, algorithms, and trustworthy decision-making in a single research pipeline.

Task 1

Single-pass graph stream processing under bounded memory and latency.

Task 2

Approximate graph representations under bounded memory and computation.

Task 3

Drift-adaptive graph learning under constrained computation.

Task 4

Robust and interpretable graph stream learning under bounded resources.
